The agent. Phone agent that registers new patients over a U.S. number in English or Spanish: a Retell LLM agent with a 14-section prompt and 5 tool-calling functions, saving to Postgres only after the caller confirms a read-back.

The API. Fastify and Zod API, Drizzle on Postgres and a Next.js dashboard; the agent’s tools and the REST API share one validation schema, webhooks are signature-checked, and 53 tests run against a real Postgres engine (PGlite). Deployed on Railway and Vercel.

The guard rails. Prompt, tool schemas and agent settings live in the repo and are provisioned by an idempotent sync script; tests keep the model’s tool schemas in step with the API and forbid retries on write tools so one confirmation can never create two records.

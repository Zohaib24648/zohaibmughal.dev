What I built

Built with

  • Next.js
  • React
  • Fastify
  • tRPC
  • Prisma
  • PostgreSQL
  • Supabase
  • Stripe Connect
  • Capacitor
  • Sentry

The payments. Stripe Connect core: payout onboarding, hybrid seat and usage-metered billing, per-invoice checkout links with three fee-split modes, idempotent webhook reconciliation.

The codebase. Type-safe Turborepo: 93 Prisma models, about 340 tRPC procedures, an Android Credential Manager plugin.

The invoices. Invoicing pipeline: quote to approval to invoice lifecycle, server and client PDF generation, public share links with view tracking and reminders.

The calendars. Two-way Google and Apple (CalDAV) calendar sync with encrypted OAuth tokens and a retryable row-locked job queue; realtime per-event crew chat on Supabase Realtime.

The safeguards. Company-enforceable TOTP MFA with hashed recovery codes, tokenized document-access approvals, and CI running ephemeral-Postgres integration tests and Playwright E2E on every PR.

What I built

Built with

The app. 21 feature modules, 823 passing tests, BLoC with clean architecture; offline request queue with replay, automatic token refresh, fault-tolerant parsing.

The features. QR check-in, wallet checkout, realtime match chat and notifications on Supabase Realtime; server-driven version gate with hard and soft update prompts.

The API. Next.js admin dashboard over a NestJS API: 48 domain modules, 190+ versioned REST endpoints, additive-only /v1 contract with OpenAPI drift gates in CI; no release broke older installs.

The payments. Payments domain (Paymob behind a pluggable gateway adapter, wallet and credits ledger, promo codes, PDF receipts); multi-actor RBAC from a shared permission matrix; API migrated from EC2 to Railway.

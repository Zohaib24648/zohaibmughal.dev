What I built

Built with

  • Next.js
  • React
  • Fastify
  • tRPC
  • Prisma
  • PostgreSQL
  • BullMQ
  • Redis
  • Better Auth
  • Docker

The codebase. Designed a 25-package Turborepo (Next.js frontend, Fastify API, BullMQ worker): 145 tRPC routers and 1,000+ procedures over a 212-model Prisma schema (dispatch, timesheets, assets, quoting, billing); money as BigInt cents.

The rules. Enforcement-first decision engine: one pure, unit-testable gate checks every dispatch, closeout and invoice transition, returns structured failure codes, and logs every block and manager override (8 live checks on the dispatch calendar).

The money. Scored two-hop reconciliation of bank transactions to supplier invoices; jobs cannot be invoiced until costs match.

The portals. Five role-scoped portals over one API across 148 page routes: internal operations, technician mobile, client and subcontractor self-service, and tokenised public links for quotes, invoices and feedback.

The suppliers. Supplier integration layer: typed adapters for eight external systems, including three trade portals with no public API (SAP Commerce and Magento storefronts) parsed server-side, plus ABN lookup and two payment feeds.

The pipeline. Infrastructure: docker-compose local parity, GitHub Actions CI building GHCR images, Railway and Vercel deploys with post-deploy smoke tests; 30,000+ tests across 2,200+ files.
